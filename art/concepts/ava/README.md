# Ava — visual concept V1

Original generated character concepts for The AI Race, created with the built-in imagegen tool. The supplied robot reference informed the broad vibe only.

- ava-full-body-v1.png: confident adult feminine robot, welcoming gesture and full character silhouette.
- ava-portrait-v1.png: matching close-up dialogue/avatar concept.

Identity: swept asymmetrical pearl-white crown, black glass visor, magenta expressive eyes and warm digital smile, cyan collar/wrist/ankle details, graphite mechanics, glossy white shell. Premium clean stylized rendering with warm key light and cool cyan rim. AI cofounder and guide, not a combat unit.

These are concept PNGs for visual review, not a tutorial implementation. Preserve the original generated files. Before shipping small UI assets, review alpha edges against the actual dialogue background and produce optimized final exports. Gameplay, onboarding, saves and deployed assets were not modified.
