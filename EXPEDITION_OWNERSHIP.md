Imports engine WORLD, rigStats, cargoCount, findPath, RIG_UPGRADE. Create gorgeous interactive SVG isometric world, mobile touch/keyboard tile actions, no external assets/services.
- Mechanics agent: src/game/expedition.ts, tests/expedition.test.ts ONLY. Pure exports WORLD: ExpeditionWorld, RIG_UPGRADE:{name:string,cost:Resources,description:string}, rigStats(level):{energy:number,capacity:number}, cargoCount(resources):number, findPath(from,to,rigLevel):Point[]|null, createExpeditionState():ExpeditionState, applyExpeditionCommand(state,command,now?):ExpeditionState. Path excludes start/includes destination. Server-authoritative allowed actions, cooldowns. Legacy engine unchanged.
- Backend agent: server/expedition-api.ts, server/expedition-api.test.ts ONLY. Exports registerExpeditions(app,db,getSession) where getSession(req,res):{id:string,state:GameState}, plus readExpedition(db,id):ExpeditionState. Registers POST /api/expedition request ExpeditionRequest => {expedition:ExpeditionState}; same-origin middleware already applied. SQLite separate tables, transactions, revision + durable request dedup. No changes to server/index.ts: parent wires module/GET Bootstrap.
- Coordinator: shared/, src/ui/App.tsx, src/styles.css, src/art/Garage.tsx, server/index.ts, docs, integration and verification. Others must not edit these.

Model contracts are in shared/expedition.ts and frozen until parent coordinates changes. All work stays inside TheAIRace. No paid AI, hosting, deployment, payments. One salvage yard, three resources, one rig upgrade. Existing game state/contract economy remains untouched.

Gameplay agreement: 7x7 isometric map, dock(0,5), basic sector x<4, upgraded sector x>=4, obstacles and energy-draining hazard shortcuts. Basic battery26/cargo12, rig battery40/cargo20. First rig costs6 scrap+2 cells, no credits. Deposits reset per departure, finite charges per run. Each gather gives3 scrap OR1 cell OR2 GPU; costs2 battery, requires adjacency and appropriate rig. Movement costs1 per tile, hazard4; server enforces readyAt based on180ms per step, gather500ms. Recharge at charger consumes1 cargo cell for+8 battery once/run. At dock Return banks all cargo; emergency Evacuate anywhere banks floor half each resource (explicit UI warning). Zero energy cannot softlock: evacuation always allowed. No reward sent by client. One active activity per Pixel: backend rejects depart with active contract and parent blocks contract start while expedition active.
